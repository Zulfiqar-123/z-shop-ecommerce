# Z-Shop – Full Stack E-Commerce Website

Z-Shop is a full-stack e-commerce web application built using React, Node.js, Express.js, and MySQL. It allows customers to browse products, add items to their cart, and place orders.

## Features

- Modern and responsive homepage
- Product listing with images
- Product search and categories
- Shopping cart
- Checkout and order placement
- Order confirmation
- Admin login
- Admin dashboard
- Manage products (Add, Edit, Delete)
- View and manage customer orders

## Technologies Used

**Frontend**
- React.js
- Vite
- Tailwind CSS

**Backend**
- Node.js
- Express.js

**Database**
- MySQL

## Project Structure

- `frontend/` – React frontend application
- `backend/` – Express backend and API
- `.gitignore` – Files excluded from Git

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/Zulfiqar-123/z-shop-ecommerce.git
cd z-shop-ecommerce
```

### 2. Install frontend dependencies

```bash
cd frontend
npm install
npm run dev
```

### 3. Install backend dependencies

Open another terminal:

```bash
cd backend
npm install
npm run dev
```

### 4. Database Configuration

- Install and start MySQL.
- Create a database named `zshop`.
- Configure database credentials in `backend/config/db.js`.
- Configure backend environment variables in `backend/.env`.

## Local Development URLs

- Frontend: http://localhost:5173
- Backend: http://localhost:5000
